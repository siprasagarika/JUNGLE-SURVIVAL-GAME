# JUNGLE-SURVIVAL-GAME
 Jungle Survival Jungle Survival is a jungle-themed survival game developed using the Godot Engine with Python-based scripting. The game focuses on exploration, resource management, and survival mechanics in a challenging jungle environment. 
## 🛠 Tech Stack

- **Game Engine:** Godot Engine  
- **Programming Language:** Python (Godot scripting)  
- **Platform:** PC  

---

## ✨ Features

- Jungle-themed environment 🌴  
- Survival-based gameplay  
- Resource management system  
- Simple and interactive mechanics  
- Beginner-friendly game logic
